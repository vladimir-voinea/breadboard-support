Privacy Policy — Breadboard: Circuit Puzzles

Effective date: October 17, 2026

The short version

Breadboard is fully playable offline — no account, no connection ever required. While you play, the app can send anonymous usage analytics to our own first-party server so we can tune level difficulty and see which features are used. It contains no name, no email, no precise location and no content you create. It is on by default and you can turn it off with one switch in Settings → “Share anonymous usage data.” When the switch is off, no usage data is gathered or sent at all. There are no ads and no third-party analytics or advertising SDKs in the app.

What we collect

Anonymous device identifier. The app computes SHA-256(salt + identifierForVendor) on your device: Apple's vendor identifier (IDFV) mixed with an app-specific salt, then irreversibly hashed. The raw IDFV never leaves your device and the hash is used only to count unique players and sessions. We never use the advertising identifier (IDFA) and the app never shows an ATT (tracking) prompt.

Device info. app_version, os_version, model — so we know which iOS versions and devices to support.

Usage events. Ten game-level events, each a name plus small numeric/ID properties:

  • install — first launch ever on a device (no properties)
  • app_open — session_id
  • app_close — session_id, duration_s
  • level_start — level_id, chapter
  • level_solve — level_id, chapter, attempts, placements, removals, burnouts, duration_s
  • level_abandon — level_id, chapter, placements, removals, burnouts, duration_s
  • burnout — level_id, component
  • tutor_used — level_id, mode (step or skip), steps_placed
  • handbook_open — page_id
  • level_replay — level_id

On the App Store privacy label these appear as Usage — Product Interaction (the events) and Diagnostics (the device info), collected for analytics purposes, not used to track you and not linked to you.

What we never collect

  • Your IP address — used only transiently for abuse rate-limiting at the network edge and immediately discarded; never stored
  • Precise location
  • Your name, email address, or any contact info
  • Any free text you type, screenshots, or the content you build
  • The advertising identifier (IDFA) — no ATT prompt is ever shown
  • Per-tap micro-events — we count what happens, not every finger movement
  • No ad or advertising-network data — the app contains no ad SDK

How the data travels

While you're online, events are sent within about a second over HTTPS to our own analytics collector — not to Google, not to any ad network, no third-party processors. The queue on your device's disk is only an offline bridge: it is written when the network is down or a send fails, drained the moment connectivity returns, purged on server confirmation, and anything still unsent after 72 hours is dropped. The healthy online path never writes analytics data to disk. Playing in airplane mode is fully supported — nothing is collected beyond what a normal, ordinary HTTPS request would involve while online.

Your control

Settings → “Share anonymous usage data” (on by default). Turning it off stops all usage-data collection immediately: nothing is queued, the existing queue is purged, and zero analytics traffic leaves the device. The game is 100% functional offline and stays fully functional with the switch off.

Retention

Raw event rows (with the anonymous device hash) are deleted after 365 days. Only fully anonymized aggregates — counts and averages with no device identifier of any kind — are kept longer, so we can compare level difficulty and retention over time.

Deletion

Want everything tied to your device erased? Email us and we'll walk you through a short support flow that reads your device's anonymous hash from the app; we then delete every raw row carrying that hash on request. Because the data is anonymous and unlinked to your identity, we can only erase rows matching that hash.

Children's privacy

Breadboard is suitable for all ages (rated 4+). There are no accounts and no user-generated content, and the usage data described above is anonymous, first-party and never used for advertising or tracking.

Future changes

If a future update ever changes what the app does with data — for example, if the dormant rewarded-ad gate (planned as an optional “solve it for me” unlock) is switched on — this policy will be updated first, with the effective date above, and the App Store privacy label will be updated to match, before that version ships.
